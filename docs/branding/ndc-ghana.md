# Ghana NDC logo

The application uses the National Democratic Congress (Ghana) umbrella emblem, stored locally at assets/img/ndc-ghana-logo.svg. The custom text-only asset is retired from all templates.

Research: https://ndc.org.gh/ identifies the Ghana party's official website. Direct asset retrieval from that website was blocked by its browser challenge. The downloaded vector is therefore a Wikimedia reproduction, not a file obtained directly from the party.
